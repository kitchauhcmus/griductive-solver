FC Online portraits

Drop a player photo here and reload the page. Transparent PNG cutouts work best.
The server checks PNG, WebP, JPG and JPEG in that order, ignoring filename case.
For example, De_Bruyne.WEBP works for /assets/players/de_bruyne. A PNG overrides
the bundled JPG. Missing or unreadable images use the player's numbered SVG kit.
